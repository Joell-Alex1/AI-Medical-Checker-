AI-Medical-Checker

AI-Medical-Checker is a backend-powered health assistant that suggests medicines based on symptoms. It uses FDA and Gemini APIs to fetch relevant data, and integrates weather-based health suggestions using the OpenWeather API. All data is stored in a structured MySQL database for efficient retrieval and analysis.

Features:
Symptom-to-medicine recommendation system

Allergy warnings for recommended drugs

Purpose and warning details for each medicine

Weather & AQI-based health tips

Built with MySQL, and public health APIs.
